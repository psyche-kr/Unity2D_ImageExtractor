# Image RGB Analyzer

폴더에 넣어 둔 이미지들의 평균 RGB를 계산해 화면에 색으로 보여 주고, 두 이미지의 색 차이를 확대해서 비교하는 Unity 도구입니다. 지인의 화학과 랩실 의뢰로 만들었습니다.

| 항목 | 내용 |
| --- | --- |
| 기간 | 2025.01.15 – 01.16 |
| 인원 | 1명 (기획부터 구현까지) |
| 엔진 | Unity 6000.0.24f1, C# |
| 스크립트 | `Assets/ImageLoader.cs` |

## 동작 방식

1. 바탕화면의 `Image` 폴더에 1번부터 32번까지 번호를 붙인 이미지(jpg, 없으면 png)를 넣고 실행합니다. 폴더가 없으면 만들고 안내합니다.
2. 이미지마다 모든 픽셀의 R, G, B를 더해 픽셀 수로 나눠 평균 색을 구하고, 32칸 격자에 그 색으로 표시합니다. 결과는 번호와 R, G, B 값(0–255)으로 `Result.txt`에 한 줄씩 기록합니다.
3. 1–16번과 17–32번을 짝지어 색 차이(채널별 절댓값)를 계산해 16칸에 표시합니다.
4. 입력창에 배율을 넣으면 색 차이에 곱해 다시 그립니다. 차이가 작아서 눈으로 구분하기 어려울 때 확대해 보려는 용도이고, 값은 0–255 범위로 제한합니다.

## 구현에서 신경 쓴 부분

- 픽셀 평균은 `Texture2D.GetPixels()`로 가져온 배열을 순회해 계산합니다.
- 이미지 읽기와 결과 파일 저장은 `async/await`로 처리해, 파일을 읽는 동안 화면이 멈추지 않게 했습니다.
- 배율 값을 바꾸면 매 프레임 갱신되어, 입력을 마치는 즉시 결과가 바뀝니다.

## 후속 버전

실험에서 이미 측정된 RGB 값(CSV)을 이미지로 바꿔 달라는 요청이 이어져 만든 [CsvToPngConverter](https://github.com/psyche-kr/CsvToPngConverter)가 있습니다.
